# Developer Portfolio

A premium, modern developer portfolio built with React and Vite.

## Features
- **Modern Dark Theme**: Designed with a sleek, developer-focused aesthetic.
- **Responsive Layout**: Works seamlessly on desktop and mobile.
- **Section Navigation**: Smooth scrolling to About, Projects, and Contact sections.
- **Project Showcase**: Distinct visual treatment for deployed services vs. research projects.

## Tech Stack
- **Framework**: React 19 (via Vite)
- **Styling**: Vanilla CSS (Modern features like CSS Variables, Grid, Glassmorphism)
- **Icons**: Lucide React
- **Font**: Outfit (via Google Fonts)

## Getting Started

1.  **Install Dependencies**
    ```bash
    npm install
    ```

2.  **Run Development Server**
    ```bash
    npm run dev
    ```

3.  **Build for Production**
    ```bash
    npm run build
    ```

## Customization
- Edit `src/App.jsx` to update your personal information and project details.
- Modify `src/index.css` to adjust the color palette or typography.
